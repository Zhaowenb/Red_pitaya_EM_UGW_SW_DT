## 已执行

- 原主线 68 项仿真/HTTP/算法/双输出相位回归通过。
- 新增 BTF 偏置电流/幅值、波形评价、连续扫描、过流/超时/USB 故障、输出未知恢复、目录命名与归档回归；最终本机全量 **159 项通过**，70.508 s。包含 DAC OFF 成功、负面确认/断线传播与仿真不访问 socket 的协议测试；不等于 C++ 实机验收。
- 参考源码指纹核验：108 个 Pico BTF 代码、网页、测试文件与导入前相同。未修改参考目录。
- 8 项同输入数值对比通过：三组零相位带通、STFT、WPD、CWT、空间—时间对称性 TEST、N/f 双接收评价。确定性 5 MS/s / 73.7 kHz / 7 周期波形；非缺陷标定试验。
- 本机浏览器实际点击实时测量仿真：两路波形、50,000 点、5 MS/s、10 ms 与仿真标识；两次输出对应数据由 API 回归覆盖。
- 共享导航、小窗口两行布局、独立磁路/干扰页返回核验；[采集截图](images/btf-measure-simulated.jpg) 为本机模型数据，不是实测。
- 浏览器实际点击偏置仿真：0 / 0.5 A、5 次重复、0.1 Vpp；数据后断电落盘，结果、逐次波形与导出。
- 递归 Node 语法检查、Git diff 空白检查通过；GitHub CI 已配置 Python 3.10/3.12 与网页检查，实际云端执行以对应提交的 Actions 状态为准。
