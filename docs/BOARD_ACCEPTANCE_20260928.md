# 2026-09-28 部署与双路相位回环验收

设备：192.168.10.68，OS 2.07 Build 48，ARMv7，Python 3.10.12，NumPy 2.2.5。
用户确认接线 OUT1→IN1、OUT2→IN2，两路 LV。
全部测试设置 0.1 Vpp、0 V 偏置、Hi-Z，未使用 0.5 Vpp 以上设置。

## 部署

板端 C++ 编译成功，原位更新 hann_scope，已有采集数据保留。
部署前原程序备份：`/opt/redpitaya/hann_scope_backups/20260928-001844`。
DDR 修正前中间版本备份：`/opt/redpitaya/hann_scope_backups/20260928-002146`。
注意默认 rollback 指向最近的中间版本，不是最初旧程序；恢复最初版本应明确使用 001844 备份。

首次安装发现官方 rw/ro 脚本依赖 PATH_REDPITAYA 环境变量，非交互 SSH 没有该变量；已在部署及回退脚本显式设置。
首次采集发现第二路 DDR 起始地址只按 8 点对齐，未满足 mmap 的 4096 字节页要求。调整为按系统页大小对齐两路缓冲区，保持实际返回 50,000 点，不截短记录。

## 实测结果

73.7 kHz；正弦 30 周期，Hann 7 周期；相位定义 OUT2 − OUT1。
取波包中段 20%–80% 做正弦/余弦/直流最小二乘拟合，比较双路相位。

| 设置 | 正弦实测 | Hann 实测 |
|---|---:|---:|
| 0° | −0.209° | −0.213° |
| 90° | 89.784° | 88.178° |
| 180° | 179.794° | 179.760° |
| −90° | −90.245° | −91.728° |

八组均通过预设 ±5° 相位容差和 0.07–0.13 Vpp 幅值检查。
实测峰峰值范围 0.09717–0.10022 Vpp；每组两路各 50,000 点，实际采样率 5 MS/s，完整 10 ms，无输入溢出。
Hann 有包络，有限窗拟合带来偏差；以上不是经校准的相位精度指标，也未扣除电缆/通道间偏差。

原始八组 NPZ 与 JSON 报告：本目录 `phase_acceptance_20260928_002202/`；板端同名目录位于 `/home/redpitaya/hann_scope_data/`。
脚本：`tools/board_phase_acceptance.py`。首组 DDR 失败记录目录保留，未生成波形。
